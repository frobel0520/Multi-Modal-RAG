# CR-001 政府鐵道運量語料

2026-11-24 已確認轉向臺鐵、捷運、高鐵。首批範圍依取得的完整年資料與開放授權選定。此變更涵蓋原計畫與系統分析的 ESG 語料、系統設計 T03/T04 的索引輸入、T09 評測題庫和發布資料驗收。舊文件保留原規劃紀錄，鐵道版本的整合設計及正式驗收依下列順序更新。

## 首批資料

期間為西元 2021–2025 年，單位皆為人次。各圖單獨顯示相對於本序列最高年的比例。

| 序列 | 範圍與統計口徑 | 來源 |
| --- | --- | --- |
| 臺鐵 | 臺北市車站客運人次，取年度「總計」 | [臺北市鐵路客貨運量](https://data.gov.tw/dataset/133177) |
| 北捷 | 臺北捷運全線客運人次，加總每年 12 個月的「總計」 | [臺北市捷運客運概況按月別](https://data.gov.tw/dataset/132092) |
| 高鐵 | 臺北市車站進站人次，取年度「高速鐵路進站人次」 | [臺北市鐵路客貨運量](https://data.gov.tw/dataset/133177) |

出處為臺北市政府主計處，採[政府資料開放授權條款第1版](https://data.gov.tw/license)。圖表由專案重新產生。來源清單記錄資料集網址、擷取日、欄位及原始檔 SHA-256。全國臺鐵與高鐵、北捷以外的營運商、班表及即時資訊不在這批資料的涵蓋範圍。高鐵全線候選 CSV 本次回傳 HTML，未能驗證；另以可核對的臺北市進站統計做首批高鐵資料。

## 驗證證據

- 資料以原始年度欄位及獨立的北捷逐月加總核對，15／15 筆相符。缺月、重複月份、雜湊不符皆拒絕。
- 2026-11-24，Windows／Intel Core i7-12700KF／Python 3.14.4，兩份真實 CSV 共 31,414 bytes、15 筆輸出。同一程序內執行 100 次本機讀取、驗證、聚合及 HTML 生成，p50 1.05 ms、p95 1.25 ms。這次只量測暖程序與本機檔案，冷啟動與正式 API 延遲待量測。
- 模型評分 `not_scored`。正式截圖檢索、文字問答與 Release Gate 待驗。

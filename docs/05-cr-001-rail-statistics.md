## 鐵道問答整合

- `/api/query` 保留同源與登入檢查。文字支援單一運具、單一西元年或民國年。也可用網頁選擇運具與西元年。逐筆使用快照值組成回答與引用。
- 截圖入口使用瀏覽器內的 Tesseract OCR。使用網頁列出的圖表，截圖需保留 `RAIL TRA`、`RAIL METRO`、`RAIL HSR` 其中一個圖表代碼，以及至少一列完整的年份和數值。網站只送出辨識到的代碼與年度值，圖片和其他辨識文字留在瀏覽器。
- API 核對所有已辨識年度值，若有指定年度也需在截圖中核對。純截圖回覆已核對的年度。若超出地理、年度與統計口徑，或截圖證據不足，回覆原因且引用為空。
- API 接收 JSON 或 multipart 的 `question`、選填 `series` 和 `year`，以及代表截圖的選填 `screenshot_evidence`。證據格式為 `{ "codes": ["METRO"], "rows": [{"year": 2024, "value": 741824511}] }`，舊版直接上傳二進位圖片會回 400。鐵道引用包含來源網址、資料集、發布機關、授權、快照版次和同源 SVG 圖表路徑。先前網頁報告問答契約由本節更新。
- 網頁辨識資源在建置時隨站點一起發布，只有截圖操作才載入。兩種問答皆可在不使用外部模型、向量資料庫或額外 API 金鑰的情況下執行。正式環境沿用 Google 登入與 KV 限流，缺少限流繫結時查詢回 503。初次 OCR 額外靜態資源約 7 MB（未計傳輸壓縮，最大單檔約 3.9 MB），在 Pages 每檔 25 MiB 限制內。正式部署須確認帳號使用免費方案與日用量。 [Pages 限制](https://developers.cloudflare.com/pages/platform/limits/) · [Functions 計費](https://developers.cloudflare.com/pages/functions/pricing/)
- 合併順序為資料 PR #21 後再合入問答。若切回上一版，回退這次問答的提交即可。未改動資料庫、登入設定或部署工作流。正式環境登入、手機實機與 Release Gate 仍待驗。

### 問答驗證

- 自動測試逐筆驗證 15 筆真實年度值。文字及截圖辨識結果兩條路徑都比對人次、單位、來源、發布機關及授權。另涵蓋未知年度、地區、統計口徑、截圖值被改、證據不足、錯誤請求及未登入。
- 2026-11-27 將現行主線的工作階段與限流修正整合進資料／問答堆疊。合成測試確認鐵道 API 拒絕檔案、數值不符時回覆無引用的拒答、符合時以官方來源與同源圖表引證。同一 KV 繫結的並行請求共用限流佇列，請求與欄位容量守門保留。缺少限流繫結時在讀取請求正文前回 503。部署、正式效能與跨 isolate 的限流行為仍待驗收。
- 本機 Edge 158 的 390 px 視窗，使用合成登入工作階段測試建置後的網頁。三種真實來源圖表均以 PNG 截圖通過 OCR、API 與引用驗證。改值及移除代碼的圖片均拒答。純截圖可回傳符合快照的年度。測試已驗證圖片未隨 API 請求送出、只使用同源資源、證據圖表可放大及以 Esc 關閉。
- 整合後 `npm run ci` 通過 56 項測試。npm 稽核未回報已知漏洞。正式系統效能、正式登入及手機實機待驗。
- 2026-11-24 本機效能。Windows、Intel Core i7-12700KF、Node 24.22.1、Edge 158、15 筆真實資料。從送出按鈕操作開始量到瀏覽器取得 API 結果，含 OCR。冷啟動首筆為文字 81.9 ms、截圖 3,219.0 ms。暖程序每模式 17 筆，文字 p50 1,030.5 ms、p95 1,950.3 ms，截圖 p50 3,102.0 ms、p95 4,192.8 ms。測試攔截外部流量，瀏覽器 HTTP 快取停用。
- 本機伺服器從接收請求到取得回覆，文字 22 筆 p50 1.0 ms、p95 1.5 ms，截圖證據 21 筆 p50 1.0 ms、p95 2.0 ms。後者不包含 OCR。本機量測與正式環境效能分開記錄。
